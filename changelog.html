Changelog

Public changelog with significant feature updates and improvements.

2026-02-24

  • Image generation mode is now live.
  • Text-to-image generation is available.
  • You can upload multiple images and generate a new image from them.
  • Added enhancement for previously generated images.
  • 3 free image generations are available every week.
  • Increased daily free Quick quota to 10 requests.
  • Reduced token prices.
  • Added a 5000-token pack for 900 Telegram Stars.

2026-02-20

  • Added a referral program in the Telegram bot.
  • Users can get a personal link and share it with friends.
  • 100 tokens are credited for each new invited user.

2026-02-19

  • Multilingual release: interface is now available in 11 languages.
  • Launched a standalone documentation site on GitHub Pages.
  • Added dedicated pages: How It Works, Status, Pricing, Privacy, FAQ, and Changelog.
  • Configured robots.txt and sitemap.xml for indexing.

2026-02-11

  • Context window reduced to the last 2 messages to lower API costs.
  • Introduced daily free quota: 10 Quick requests for subscribers.

2026-02-07

  • First-week summary: 75 users tried the bot.
  • 50 users subscribed to the project Telegram channel.
  • Processed over 3000 requests.
  • API costs for the first week were around $17.
  • Published a cost analysis for long chat sessions.
  • Confirmed that sending full context significantly increases per-request costs.
  • Decided to keep only a short recent context as a quality/cost compromise.

2026-02-06

  • Published roadmap update with mode expansion.
  • Announced modes: Quick (default), Smart, Internet, and Images.
  • Introduced monetization model for additional modes with limited free usage.

2026-02-05

  • Bot started replying directly to user messages for clearer threads.
  • Added typing indicator during response generation.

2026-02-02

  • Added richer response formatting for readability.
  • Improved output structure for long text and code answers.

2026-01-30

  • Released the first working version of the bot.
  • At launch, dialogue context was not preserved.
  • Added English localization.
  • Initial access required channel subscription.

2026-01 to 2026-02

  • Added New Chat button to reset current context.
  • Added mode switcher: Quick, Smart, Internet, and Images.
  • Internet mode gained support for fresh information lookup.
  • Added token top-up packs in the payment menu.
