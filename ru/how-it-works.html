Как работает AI-чатбот в Telegram

На этой странице подробно описано, как работает бот Grok в Telegram: как обрабатываются запросы, как сохраняется контекст диалога и как обеспечивается стабильная работа сервиса.

Поток запроса

 Сообщение пользователя в Telegram         |         v Сервис бота (авторизация, квота, базовые проверки)         |         v Запрос к Grok API         |         v Сервис бота форматирует ответ         |         v Ответ пользователю в Telegram

Какой контекст запоминается

  • Для поддержания диалога используется только краткосрочный контекст из двух последних сообщений.
  • Долгосрочное хранение полной истории переписки не осуществляется.
  • Команда New Chat немедленно сбрасывает контекст текущей сессии.

Какие данные используются

  • Идентификатор пользователя Telegram — для проверки лимитов, баланса и подписки.
  • Текст текущего запроса и краткий контекст — для формирования ответа.
  • Технические данные, необходимые для учёта запросов и доставки ответа.

Поведение чата

  • Бот отвечает как ответ на ваше сообщение, сохраняя структуру переписки.
  • Пока формируется ответ, отображается индикатор набора сообщения.
  • Ответы поддерживают форматирование текста, включая удобные блоки кода.

Доступные режимы

  • Quick (по умолчанию) — быстрый и экономичный режим для повседневных задач: ответы на вопросы, помощь с текстами, идеи, простые объяснения.
  • Smart — более продвинутый режим для сложных запросов, глубокого анализа, работы с кодом и развёрнутых ответов.
  • Internet — режим с доступом к актуальной информации из интернета для поиска свежих данных и фактов.
  • Images — режим генерации изображений по текстовому описанию, а также анализ отправленных картинок.
  • Expert — продвинутый режим для сложных задач: глубокий анализ, подробные объяснения, работа с кодом и разбор нестандартных запросов.

Задержка и надёжность работы

  • Время ответа зависит от текущей загрузки Grok API и сложности запроса.
  • При кратковременных технических сбоях бот автоматически выполняет повторную попытку обработки запроса.
  • В большинстве случаев повторная отправка сообщения пользователем не требуется.
