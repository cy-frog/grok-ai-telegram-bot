Обновления

Публичный журнал обновлений с описанием значимых изменений и улучшений.

24/02/2026

  • Запущен режим генерации изображений.
  • Доступна генерация изображений по текстовому описанию.
  • Можно загружать несколько изображений и создавать новое на их основе.
  • Добавлена возможность улучшения ранее созданных изображений.
  • Каждую неделю доступно 3 бесплатные генерации изображений.
  • Увеличен ежедневный бесплатный лимит Quick-запросов до 10.
  • Снижена стоимость токенов.
  • Добавлен пакет 5000 токенов за 900 Telegram Stars.

20/02/2026

  • Добавлена реферальная программа в Telegram-боте.
  • Пользователи могут получить персональную ссылку и делиться ею с друзьями.
  • За каждого нового пользователя начисляется 100 токенов.

19/02/2026

  • Выпущен мультиязычный релиз: интерфейс доступен на 11 языках.
  • Запущен отдельный сайт документации на GitHub Pages.
  • Добавлены страницы: «Как это работает», «Статус», «Цены», «Приватность», «FAQ» и «Обновления».
  • Настроены robots.txt и sitemap.xml для корректной индексации в поисковых системах.

11/02/2026

  • Окно контекста сокращено до двух последних сообщений для оптимизации затрат на API.
  • Введён ежедневный бесплатный лимит: 10 запросов в режиме Quick для подписчиков.

07/02/2026

  • Итоги первой недели: 75 пользователей попробовали бота.
  • 50 пользователей подписались на Telegram-канал проекта.
  • Обработано более 3000 запросов.
  • Расходы на API за первую неделю составили около 17 $.
  • Опубликован анализ затрат при длинных диалогах.
  • Выявлено, что передача полного контекста значительно увеличивает стоимость запроса.
  • Принято решение ограничить контекст несколькими последними сообщениями как компромисс между качеством и стоимостью.

06/02/2026

  • Опубликован план развития с расширением режимов работы.
  • Анонсированы режимы: Quick (по умолчанию), Smart, Internet и Images.
  • Представлена модель монетизации дополнительных режимов с ограниченным бесплатным использованием.

05/02/2026

  • Бот начал отвечать напрямую на сообщение пользователя для более структурированной переписки.
  • Добавлен индикатор набора сообщения во время генерации ответа.

02/02/2026

  • Добавлено расширенное форматирование ответов для лучшей читаемости.
  • Улучшена структура вывода для длинных текстов и ответов с кодом.

30/01/2026

  • Релиз первой рабочей версии бота.
  • На старте контекст диалога не сохранялся.
  • Добавлена английская локализация.
  • Доступ к боту на первом этапе требовал подписки на канал.

01/2026 — 02/2026

  • Добавлена кнопка New Chat для сброса текущего контекста.
  • Добавлен переключатель режимов: Quick, Smart, Internet и Images.
  • Режим Internet получил поддержку поиска актуальной информации.
  • Добавлены пакеты пополнения токенов в платежном меню бота.
