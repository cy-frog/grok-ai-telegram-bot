Приватность и обработка данных

На странице разъясняется, какие данные необходимы для функционирования бота, как обеспечивается их обработка и какие сведения не подлежат долгосрочному хранению.

Какие данные используются

  • Идентификатор пользователя Telegram — для проверки лимитов, баланса и подписки.
  • Информация о балансе, статусе подписки и платёжных операциях.
  • Технические события, необходимые для стабильной работы сервиса и предотвращения злоупотреблений.

Что не сохраняется на постоянной основе

  • Полная история переписки не хранится как база данных сообщений.
  • Тексты запросов и ответы модели не сохраняются как долгосрочный архив.
  • Диалоги не формируют постоянную историю чата на стороне сервиса.

Краткосрочный контекст

  • Для связности диалога к текущему запросу добавляются два последних сообщения.
  • Контекст используется только для обработки запроса и передаётся в Grok API без долгосрочного хранения на стороне сервиса.
  • Сообщения не сохраняются как постоянная история переписки.
  • Кнопка New Chat очищает активный контекст и начинает новый диалог.

Обработка и безопасность

  • Запросы передаются через сервер бота к официальному Grok API.
  • Доступ к системам ограничен уполномоченными лицами.
  • Диагностические журналы не содержат полного текста сообщений.
